# Actor

Actor is a local-first AI workbench for software teams. It brings agent chat, project context, terminal workflows, files, permissions, personas, and first-party app integrations into one desktop surface.

Actor is built for people who want AI agents to work inside their actual development environment, with access to local repositories and explicit approval gates for sensitive actions.

## About This Repository

This repository is the public release channel for the Actor desktop app.

It contains published desktop release artifacts and update metadata used by the app's auto-update system. It does not contain Actor source code, product internals, signing secrets, or development history.

The source repository is private. This release repository is public so desktop clients can check for updates without embedding a GitHub token.

## Downloads

Desktop builds are published on the GitHub Releases page for this repository.

Each release may include macOS, Windows, or Linux builds depending on platform availability.

## Updates

Actor desktop uses this repository to discover and download app updates.

Stable builds receive stable releases. Prerelease builds may receive newer prerelease versions.

Do not commit source code or secrets to this repository.
